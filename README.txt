TRICK THE TROLL — GitHub Pages site

Upload index.html and logo.png to the root of your public GitHub repository.
In repository Settings > Pages, choose Deploy from a branch, main, / (root).
In Settings > Pages > Custom domain, enter www.watchmeyoubastards.com.
At your domain registrar, create a CNAME record: www -> YOUR_GITHUB_USERNAME.github.io
For the root domain, add A records:
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
Enable Enforce HTTPS once DNS verification is complete.

Note: The YouTube embed attempts muted autoplay after 4 seconds.
Browsers generally prevent autoplay with sound. The Turn on sound button
reloads the video with audio after a visitor clicks it.
